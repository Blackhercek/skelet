# Как передать проект Claude (для вас, не для Claude)

1. Распакуйте zip — получится папка `body-atlas`.
2. Создайте на github.com **пустой** репозиторий (например, `anatomy-atlas`, без README) и загрузите в него содержимое папки `body-atlas` (команды есть в файле `ЗАПУСК.md`, раздел «через GitHub»).
3. Запустите Claude с доступом к этому репозиторию (Claude Code на сайте или в терминале) и дайте ему это сообщение:

> Прочитай `CLAUDE.md` и `claude-task/TASK.md` в этом репозитории и выполни задание целиком: опубликуй атлас на GitHub Pages, проверь, что всё работает (на компьютере и на iPhone-профиле в WebKit, включая работу без интернета), исправь найденные проблемы и пришли мне короткий отчёт на русском со ссылкой и таблицей проверок. Если нужно моё решение или действие, спроси.

4. Получив ссылку, откройте её на iPhone в Safari → «Поделиться» → «На экран «Домой»».
