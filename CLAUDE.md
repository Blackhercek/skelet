# Инструкции для Claude

Это проект «Атлас тела человека» (3D-атлас анатомии на русском языке).

**Если пользователь просит опубликовать и проверить атлас — сначала прочитай `claude-task/TASK.md` и выполни его целиком.**

Кратко о проекте:
- Стек: React 19 + three.js + Vite, TypeScript; всё статическое, сервера нет.
- Сборка: `npm ci && npm run build` → папка `dist/`. Проверки: `npm run validate`.
- Весь интерфейс, описания и названия структур — на русском языке. Не добавляй английских надписей в интерфейс.
- Данные (`public/models`, `public/organs`) не изменять без явной просьбы: они имеют лицензию CC BY 4.0 и проверены скриптами.
- Подробности — в `README.md`, `ЗАПУСК.md` и `claude-task/TASK.md`.
