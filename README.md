# Атлас тела человека

Интерактивный 3D-атлас анатомии на русском языке — по мотивам приложения «Human Body Atlas» из видео. Работает прямо в браузере, без аккаунтов и ключей.

## Что умеет

- **Разведение структур** — ползунок «Развести структуры»: от собранного тела до «каждой детали по отдельности» (≈2 230 деталей); «Собрать» возвращает всё на место.
- **Виды** — спереди, сзади, сбоку, перспектива; **Мужчина / Женщина** (две эталонные модели).
- **Структуры на трёх языках** — русское название, латинское (Terminologia Anatomica, где есть устоявшийся термин) и английское; поиск по любому из них.
- **Слои, системы, области тела**, «Избранное», **срез тела** (горизонтальный, сагиттальный, фронтальный), **снимок** для презентации.
- **Органы в 3D** — лёгкие, сердце, головной мозг: слои и метки с подсказками.
- **«Проверь себя»** — тест: «Что подсвечено?» и «Найди на модели», выбор раздела и сложности, итоги раунда, повтор ошибок, статистика на устройстве.
- **iPhone и другие устройства** — установка на экран «Домой», работа без интернета, облегчённая модель для телефонов. Подробности — в файле [ЗАПУСК.md](ЗАПУСК.md).

## Запуск

Дважды щёлкните `Запустить атлас.command` (Mac): откроется браузер, а в окне появится QR-код для iPhone в той же Wi-Fi. Для ссылки «навсегда» и офлайн-режима загрузите папку `dist` на бесплатный хостинг — инструкция в [ЗАПУСК.md](ЗАПУСК.md).

Для разработки (нужен Node.js 22.13+): `npm ci`, `npm run dev`, `npm run build`, `npm run serve`, `npm run validate`.

## Данные и лицензии

- **Мужская модель** — BodyParts3D 4.0, © The Database Center for Life Science, лицензия **CC BY 4.0** (2 234 детали, 3 432 названные структуры).
- **Женская модель и органы** — 3D-эталонные органы HuBMAP Human Reference Atlas v1.5 (Kristen Browne, Heidi Schlehlein), лицензия **CC BY 4.0**. У женской модели скелет и мышцы представлены частично. Подробные сердце, лёгкие и мозг взяты из этого набора и одинаковы для обеих моделей.
- **Код просмотрщика** — основан на открытом проекте [human-atlas](https://github.com/ashemag/human-atlas) (лицензия MIT) и существенно доработан.
- **Русские названия** (≈4 100 терминов) и тексты интерфейса и описаний подготовлены для этого проекта; словарь лежит в `public/models/names-ru.json`.

Подробности об изменениях геометрии — в `public/ATTRIBUTION.md`. Атлас учебный: он не предназначен для диагностики и хирургического планирования.

## Устройство проекта

| Путь | Назначение |
| --- | --- |
| `app/page.tsx` | интерфейс: обзор, поиск, карточка структуры, нижний «док» |
| `app/scene.tsx` | 3D-сцена тела: батчинг деталей, разведение, «призрачный» режим, камера |
| `app/organ-viewer.tsx`, `app/organs.ts` | органы в 3D: слои, метки, подсказки |
| `app/regions.ts` | деление тела на области |
| `app/localize.ts` | подстановка русских названий |
| `scripts/` | подготовка и проверка данных (`extract-organs.mjs`, `validate-*.mjs`) |
