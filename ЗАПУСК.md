# Как запустить атлас на любом устройстве (iPhone — в первую очередь)

Атлас — это обычный сайт без сервера и без регистрации: достаточно положить папку `dist` на любой хостинг статических файлов. Ничего не собирается на стороне сервера, данные пользователей не собираются.

## Самый быстрый путь для iPhone: ссылка из интернета (2 минуты, бесплатно)

Чтобы атлас открывался на iPhone по ссылке, устанавливался на экран «Домой» и **работал без интернета**, ему нужен защищённый адрес `https://…`. Это даёт любой бесплатный хостинг статики. Проще всего **Netlify Drop** (регистрироваться для пробной публикации не нужно):

1. Откройте на компьютере страницу https://app.netlify.com/drop
2. Перетащите на неё папку **`dist`** (из папки проекта `body-atlas`). Загрузка идёт 1–3 минуты — в папке около 250 МБ.
3. Netlify сразу покажет ссылку вида `https://что-то-там.netlify.app`. Это и есть адрес атласа. Его можно отправить студентам, поставить в QR-код на слайд и в электронный журнал.
4. Чтобы ссылка не пропала через час, зарегистрируйтесь в Netlify (бесплатно) и привяжите сайт к аккаунту — тогда его можно переименовать и подключить собственный домен вуза.

### Вариант «просто через GitHub» (без своего сервера, бесплатно)

GitHub Pages раздаёт готовые файлы сам — свой сервер не нужен. В проекте уже есть автоматическая сборка и публикация (`.github/workflows/pages.yml`).

1. Создайте на github.com пустой репозиторий (например, `anatomy-atlas`), **без** README.
2. В терминале выполните (подставьте свой логин):

```sh
cd ~/body-atlas
git init -b main
git add .
git commit -m "Атлас тела человека"
git remote add origin https://github.com/ВАШ_ЛОГИН/anatomy-atlas.git
git push -u origin main
```

3. В репозитории откройте **Settings → Pages → Build and deployment → Source: GitHub Actions**.
4. Подождите 2–4 минуты (вкладка **Actions** покажет сборку). Адрес атласа: `https://ВАШ_ЛОГИН.github.io/anatomy-atlas/` — это `https://`, поэтому на iPhone работают установка на экран «Домой» и офлайн-режим.

Размер проекта около 270 МБ (отдельные файлы — до 5 МБ), в лимиты GitHub он укладывается. Репозиторий может быть публичным или (на платном тарифе) приватным.

Другие варианты (суть та же — выложить папку `dist`):
- **Cloudflare Pages** → «Create a project» → «Upload assets» → перетащить `dist`.
- **Сервер кафедры/вуза** → скопировать `dist` в каталог любого веб-сервера (nginx, Apache, IIS); адрес должен быть `https://`.

## Установка на iPhone (как приложение)

1. Откройте ссылку в **Safari** (именно в Safari, не в Telegram и не в Chrome).
2. Нажмите кнопку **«Поделиться»** (квадрат со стрелкой вверх внизу экрана).
3. Выберите **«На экран «Домой»»** → «Добавить».
4. На рабочем столе появится значок «Анатомия». Он открывается на весь экран, без адресной строки.
5. Один раз откройте **Настройки (значок «i» в панели «Обзор») → «Скачать для работы без интернета»**. После этого атлас работает в метро, в самолёте и в аудитории без Wi-Fi.

Атлас сам предлагает установку на iPhone — вверху появляется подсказка.

## Быстро показать атлас на iPhone без интернета-хостинга (тот же Wi-Fi)

1. На Mac дважды щёлкните **`Запустить атлас.command`** (или выполните `npm run serve`).
2. В окне появится QR-код. Наведите на него камеру iPhone и откройте ссылку.
3. Компьютер и телефон должны быть в одной сети Wi-Fi.

Это хороший вариант для демонстрации на паре. Но по адресу `http://…` (без защиты) iPhone не включает офлайн-режим — для него нужен хостинг из раздела выше.

## На компьютере (Mac, Windows, Linux)

- Mac: `Запустить атлас.command`.
- Любая система с Node.js 22+: `npm ci`, затем `npm run build` и `npm run serve`.
- Для разработки: `npm run dev`.

## Если на старом iPhone «тормозит» или страница перезагружается

- Откройте **Настройки → «Качество 3D-модели» → «Лёгкое»**. Эта версия автоматически выбирается на телефонах: в ней в 2,5 раза меньше треугольников и она в два раза быстрее загружается.
- Закройте другие вкладки и приложения; выключите «Режим энергосбережения».
- Сначала загрузится мужская (≈15 МБ в лёгком качестве) или женская (≈7,5 МБ) модель — по Wi-Fi это секунды. Органы в 3D докачиваются при первом открытии (≈9 МБ).

## Для кафедры и университета

- Приложение статическое: его можно разместить на собственном сервере вуза, ничего не отправляется во внешние сервисы, нет аккаунтов и рекламы.
- Прогресс теста и «Избранное» хранятся только на устройстве пользователя.
- Лицензии данных (CC BY 4.0) требуют указывать авторов — они уже указаны в приложении («Настройки и сведения»).
- Латинские названия приведены по Terminologia Anatomica там, где есть устоявшийся термин; для остальных структур латинского названия нет — приложение не выдумывает его.
- Приложение учебное: не предназначено для диагностики и хирургического планирования.

## Важно знать (честные ограничения)

- Я проверил атлас в браузере на компьютере и в эмуляции телефона. **На настоящем iPhone его не запускали**: на компьютере разработчика нет симулятора iOS. Всё сделано по правилам iOS (безопасные зоны, установка на экран «Домой», облегчённая модель, экономная прорисовка), но первый запуск на вашем iPhone стоит проверить и сообщить, если что-то работает не так.
- На iOS 15 и 16.0–16.3 данные скачиваются в несжатом виде (в 1,7 раза больше), на iOS 16.4+ — в сжатом.
- Safari может удалять данные сайтов, которыми не пользуются неделю. Если атлас **установлен на экран «Домой»**, этого не происходит.
